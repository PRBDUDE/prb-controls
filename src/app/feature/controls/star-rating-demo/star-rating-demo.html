Star Rating Control

Here are the prompts (in the order that I used them) used to generate the Star Rating control:
  • create a 5 star rating control in angular 22 - when the 4th star is clicked on, stars 1 through 4 should highlight and the control should return a value of 4 - when the 1st star is clicked on only the first star should highlight and a value of 1 should be returned
  • setting maxStars to 10 does nothing
  • set fill to transparent until selected
HTML - Control usage < prb-star-rating [(rating)] = selectedRating />

rating : is a two way input/out property showing the rating in a numeric value.

maxStars : is a numeric input telling the control how many stars to display. Default value is 5.

disabled : is a boolean

maxStars is not set

Selected Rating: {{ selectedRating }}

HTML - Control usage < prb-star-rating [(rating)] = selectedRating2 [maxStars] = "10" />

rating : is a two way input/out property showing the rating in a numeric value.

maxStars : is a numeric input telling the control how many stars to display. Default value is 5.

disabled : is a boolean

maxStars is set to 10

Selected Rating: {{ selectedRating2 }}
