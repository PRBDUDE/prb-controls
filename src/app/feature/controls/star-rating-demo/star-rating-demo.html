AI Prompts Here are the prompts (in the order that I used them) used to generate the Star Rating control:
  • create a 5 star rating control in angular 22
  • when the 4th star is clicked on, stars 1 through 4 should highlight and the control should return a value of 4
  • when the 1st star is clicked on only the first star should highlight and a value of 1 should be returned
  • setting maxStars to 10 does nothing
  • set fill to transparent until selected
HTML - Control usage
< prb-star-rating
[(rating)] = "'{{ selectedRating }}'" [disabled] = "'{{ disabled() }}'"
/>

rating : is a two way input/out property showing the rating in a numeric value.

maxStars : is a numeric input telling the control how many stars to display. Default value is 5.

disabled : is a boolean

The control can be disabled.

maxStars is not set

Selected Rating: {{ selectedRating }}
