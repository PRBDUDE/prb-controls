Star Rating Control

HTML <prb-star-rating [(rating)]=selectedRating />

rating: is a two way input/out property showing the rating in a numeric value.

maxStars: is a numeric input telling the control how many stars to display. Default value is 5.

disabled: is a boolean

maxStars is not set

Selected Rating: {{ selectedRating }}

HTML <prb-star-rating [(rating)]=selectedRating2 [maxStars]="10" />

rating: is a two way input/out property showing the rating in a numeric value.

maxStars: is a numeric input telling the control how many stars to display. Default value is 5.

disabled: is a boolean

maxStars is set to 10

Selected Rating: {{ selectedRating2 }}
