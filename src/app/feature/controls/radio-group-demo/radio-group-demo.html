Radio Group

This control is a group of radio buttons defined by an array of name/value pairs.

Here is the interface used to contain the name/value pairs.

export interface RadioOption<T = any> {
label: string; value: T;
}

< radio-group
[options]="'{{ JSON.stringify(selectionOptions) }}'" [name]="'options'" [orientation]="'{{ orientation() }}'" [(ngModel)]="'{{ selectedOption() }}'" [disabled]="{{ disabled() }}"
/>

The control can be oriented vertical or horizontal.

The control can be disabled.
