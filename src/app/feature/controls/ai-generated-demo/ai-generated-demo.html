I am using Google's AI Gemini to generate controls.

How you prompt the AI is important. My prompts contain "angular 22" to let the AI know I want a control generated for Angular version 22. It is important to provide as much information in your prompt to AI so you get what you expect.

Angular controls should be generated for use in Forms. This requires ControlValueAccessor to be implemented in the control. The AI does not always include this in the result. To ensure the control includes the ControlValueAccessor, you must include that in the prompt.

An AI generated control or any code for that matter should only be used when you really understand the language. Otherwise, you will get something which you do not understand.

Always review the results from the AI and make adjustments as needed.

Caution:

DO NOT USE AI with the expectation that it will correctly write what you want. You must first know the language you are asking AI to write the code in. The prompt you use must be clear and complete. Otherwise, you will get unexpected results.
