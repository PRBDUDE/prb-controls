One Button Control for Three Buttons

One control with Three Selectors. The selector determines which styling to be used for the button.

The ":host(selector-name) button {}" is used to style a specific control selector for the button.

Selectors: button-primary, button-secondary, button-tertiary

These buttons are from the same control. The only difference is the selector used. Styling for each selector is accomplished using the ":host() button" styling class.
